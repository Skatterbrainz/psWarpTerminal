# Get-WarpEnvironmentImage

## SYNOPSIS

Retrieves a list of Warp environment images.

## SYNTAX

### Default

```
Get-WarpEnvironmentImage [<CommonParameters>]
```

## DESCRIPTION

This function invokes the Warp CLI to list all available environment images.
