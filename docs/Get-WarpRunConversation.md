# Get-WarpRunConversation

## SYNOPSIS

Retrieves a run conversation by conversation ID.

## SYNTAX

```powershell
Get-WarpRunConversation -ConversationId <string> [<CommonParameters>]
```

## DESCRIPTION

Wraps `run conversation get`.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-WarpRunConversation -ConversationId "conv_abc123"
```
